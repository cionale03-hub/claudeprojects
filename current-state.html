CareLinx Base Referral Form — Recommended Structure

Updated against the fuller current-implementation export: 4,137 field entries across 126 live lead-acquisition programs (up from the original 62-program sample). First Name, Last Name, and Email are used by every one of the 126 programs; Care for (97%) and Phone (94%) are used by nearly all. Everything else is organized into the sections every program-level form already groups it into, with the fields used by most programs kept in the base flow and the fields only a handful of programs need pulled out into optional modules a program can switch on.

This pass also adds a visibility read on each field: the dataset now flags hidden per field per program, so for the first time we can see what's actually shown to the person filling out the form versus what's set automatically or by staff. Overall, 25% of all 4,137 field entries are hidden — look for the X% hidden badge below on any field where that share is meaningful.

Each card below mirrors the live product's per-step layout (italic section label, bold form title, stacked labeled fields) so this reads as a walkthrough of the consolidated flow, not just a field list.

How it works: Five9's IVR/agent-assist layer streams the call to a speech-to-text + intent-matching pipeline. Matched fields fill in live, with low-confidence matches left blank for the agent or referrer to confirm rather than guessed. Nothing here changes which fields exist above — it's a second way to fill the same fields, so hidden/system fields stay exactly as governed by each program's existing rules.
